Rare-event jump/dip trader for the make.fun 24h BTC race: it trades Coinbase Wrapped BTC (cbBTC) against USDC, minute by minute, with paper money only. The bot sits in cash almost all the time and buys full size only on a sharp 1–2 minute jump or a violent 15-minute washout, exiting on a fixed take-profit, stop-loss or max hold. Standard library only, deterministic.

## Run it

```sh
python3 -P -s main.py
```
